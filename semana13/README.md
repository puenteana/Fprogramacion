# Cálculo de salario semanal

Estudiante: Ana Paula Proaño Puente

## Descripción

Este proyecto desarrolla una función en Python para calcular el salario semanal de una persona a partir de las horas trabajadas y el pago por hora.

La función recibe dos parámetros: las horas trabajadas y el pago por hora. Luego realiza la multiplicación de estos valores y devuelve el salario semanal mediante `return`.

El programa llama a la función desde el bloque principal y muestra el resultado en la consola.
